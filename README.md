# homebrew-tap

Official Homebrew tap for [Goni Sulaiman](https://github.com/gonisulaimann)'s developer tools and packages.

## Installation

Add this tap to Homebrew:

```bash
brew tap gonisulaimann/tap
```

## Available Formulas

### Grounded (`grounded`)

Deterministic reference and comment integrity checker. Zero dependencies.

```bash
brew install gonisulaimann/tap/grounded
```

Or run directly:

```bash
brew install grounded
```
*(after tapping)*

Verify installation:

```bash
grounded --help
```
